# Project Requirements

## Project Title

Development of an Online Verification System for Weighing and Measuring Instruments Under the Legal Metrology Act, 2009 and the Legal Metrology (General) Rules, 2011.

## Objective

The objective of this project is to develop an online system for managing the verification and re-verification of weighing and measuring instruments.

The system will digitize the existing manual processes such as application submission, scheduling, verification, certificate generation, record keeping, and validity tracking.

## Main Features

1. User registration and login
2. Instrument registration
3. Online verification application
4. Verification and re-verification management
5. Verification scheduling
6. Officer allocation
7. Digital recording of verification observations
8. Digital certificate generation
9. QR-code based certificate verification
10. Verification history
11. Certificate validity tracking
12. Expiry notifications
13. Dashboard and reports
14. Search and filtering
15. Document and photograph upload
16. Role-based access control
17. Certificate printing and export

## Main Users

### 1. Admin
- Manage users
- Manage officers
- Manage instruments
- Monitor applications
- View reports and dashboards

### 2. Applicant / Business User
- Register instruments
- Submit verification applications
- Upload required documents
- Track application status
- Download certificates
- View verification history

### 3. Legal Metrology Officer
- View assigned applications
- Schedule verification
- Enter verification observations
- Record pass/fail results
- Approve or reject verification

### 4. GATC / Verification Centre
- Manage assigned verification activities
- Record inspection details
- Upload supporting photographs
- Submit verification results

### 5. Public User
- Verify a certificate using its QR code
- View basic certificate validity information

## Basic Workflow

Applicant registers instrument
→ submits verification application
→ application is reviewed
→ verification is scheduled
→ officer performs verification
→ observations are recorded
→ instrument is approved or rejected
→ digital certificate is generated
→ QR code is generated
→ certificate validity is tracked
→ expiry reminder is sent
